# DavidLaBar.com

Custom React/Vite portfolio site built to demonstrate front-end UI, animation, modular SCSS, accessible interaction patterns, and design-to-code implementation.

## Tech

- React
- Vite
- SCSS
- GSAP
- Three.js
- React Router

## Front-End Focus

- Modular component structure
- Route-based project pages
- Responsive SCSS architecture
- Accessible modal behavior
- SVG interface assets
- Page transition and overlay behavior
- Three.js scene controls
